Armadillo is a password manager for the web, Windows desktop, and Android. It brings vault search, folders, and credential imports into one app, with local-file and cloud sync options.

The project includes:

- Client-side vault encryption and encrypted cloud sync.
- Passkey quick unlock on desktop and web, plus biometric unlock and autofill on Android.
- Imports from Google Password Manager and KeePass.
- A separate admin app and foundations for team access controls.

Armadillo is currently in beta and under active development.
